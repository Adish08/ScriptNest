## What's this?

ScriptNest is my personal collection of userscripts built for **Violentmonkey**, **Tampermonkey**, and modern userscript managers.

Each script exists because I got annoyed by something, spent too much time fixing it, and decided someone else might benefit from the solution.

Some scripts improve websites.  
Some remove clutter.  
Some add missing features.  
Some exist purely because I thought:

> "Surely someone has already made this."

And then nobody had.

---

## Philosophy

The modern web has become:

- heavier
- noisier
- slower
- full of things asking for your attention

ScriptNest goes in the opposite direction.

| We do | We don't |
|---------|---------|
| Solve annoying problems | Build products for the sake of building products |
| Improve existing experiences | Chase GitHub stars |
| Add missing functionality | Wrap AI around everything |
| Keep scripts simple and lightweight | Rebuild entire browsers |

---

## ⚡ Quick Install

With **Violentmonkey**, **Tampermonkey**, or **FireMonkey** installed, **clicking on any script name** (or its install link) will open the raw script directly. Your userscript manager will automatically detect the file and prompt you to install it with a single click!

## Installation Guide

### Step 1: Install a Userscript Manager
You'll need a browser extension to manage and run userscripts. Recommended options:
- [Violentmonkey](https://violentmonkey.github.io/) (Recommended — open-source, lightweight, fast)
- [Tampermonkey](https://www.tampermonkey.net/)
- [FireMonkey](https://addons.mozilla.org/firefox/addon/firemonkey/) (Firefox)

### Step 2: One-Click Install
Click on any **Script Name** or **Install** link in the tables above. Your userscript manager will recognize the `.user.js` extension and automatically open its installation prompt.

### Step 3: Confirm Installation
Click **Install** (or **Confirm installation**) in the manager popup window.

### Step 4: Forget it exists
The best script is the one you never have to think about again.
